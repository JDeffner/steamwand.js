# Changelog

Notable changes per release. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project
follows [semantic versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Offline offset regression tests for the 39 structs the curated layers
  decode, cross-checked against steamworks-sys bindgen layouts.
- CI packs the tarball and imports it from CommonJS and ESM on Windows, Linux,
  and macOS across Node 20, 22, and 24.
- Generated doc remarks on call-result methods point at `steam.async` and pass
  the callback id to `callResultStruct`.

### Changed

- Node 20 or newer is required. pnpm is pinned through `packageManager`, and
  build scripts for koffi and esbuild are declared off so installs stay quiet.

## [0.5.0] - 2026-09-03

### Added

- Six curated layers: `social`, `overlay`, `auth`, `system`, `capture`, and
  `controllers`, over `ISteamFriends`, `ISteamUser`, `ISteamUtils`,
  `ISteamScreenshots`, and `ISteamInput`. Each ships a live test on appid 480.
- `steam.once`, for calls that answer through a broadcast callback instead of a
  call result.
- Linux ARM64: Valve's redistributable plus the platform mapping that picks it.
- Workshop queries read back item metadata and key/value tags. Records built
  from Steam-supplied keys use a null prototype.

### Changed

- koffi 3.2, TypeScript 7, and vitest 4. koffi 3 ships ESM-only typings, so the
  CommonJS build resolves it through `nodenext`; TypeScript 7 needs an explicit
  `rootDir` in the build config.
- `auth.getSessionTicket()` no longer takes the reserved identity parameter. It
  was always ignored, because `SteamNetworkingIdentity` carries a C union that
  this binding excludes.

### Fixed

- Calls through a closed session now throw instead of reaching the unloaded
  library.

## [0.4.0] - 2026-09-03

### Added

- Workshop app and item dependencies, wrapping the five dependency call
  results, so a collection can adopt children and an item can require a DLC.
- Workshop updates take `metadata`, `keyValueTags`, extra preview images and
  videos, and preview removal.
- Workshop queries return collection children and additional previews.
- `steam.dlc` lists the running app's DLC. The name avoids shadowing the
  generated `steam.apps` accessor.

### Fixed

- Lobby data keys come back recased by Steam. The behavior is documented and
  the live test matches by value.

## [0.3.0] - 2026-09-01

### Added

- Curated `stats`, `cloud`, `leaderboards`, and `lobbies` layers, written
  against the same shape as `workshop`.
- The Steam Input and Controller action-data calls, previously skipped, are
  bound through generated by-value struct support.

### Changed

- The dispatch pump pins every async call to the callback id its caller
  expected, so a mismatched completion rejects instead of decoding garbage.

### Fixed

- The live test accepts Steam refusing global achievement percentages on
  Spacewar rather than failing on it.

## [0.2.1] - 2026-09-01

### Changed

- The publish workflow refuses a tag that is not an ancestor of `main` or that
  does not match `package.json`, and it publishes to GitHub Packages as
  `@jdeffner/steamwand.js` after npmjs succeeds.

## [0.2.0] - 2026-09-01

First published release. The generator, the runtime, and the curated workshop
layer were all written before this tag; 0.1.0 was never published.

### Added

- `steam.async`: promise wrappers for the 76 flat calls that return a
  `SteamAPICall_t` with a decodable result struct.
- A lazy getter per interface, so all 25 interfaces are reachable directly off
  the session.
- Typed callbacks: `steam.on` is keyed by the generated `SteamCallbackMap`, so
  callback names and listener payloads are checked at compile time.
- The `out` helpers for the flat API's out-buffer parameters.
- Top-level `restartAppIfNecessary()` and `isSteamRunning()`, usable before
  `init()`.

### Changed

- 64-bit scalar parameters are `bigint` only, no longer `bigint | number`.
